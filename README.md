# Tarea-2-Progra1
Tarea 2 del curso de Principios de Programación 1

Problema 1. Cajero automático

Un cajero automático permite al usuario realizar varios retiros consecutivos sobre un
mismo saldo inicial hasta que decida salir o hasta que no tenga fondos suficientes. El
saldo inicial de la cuenta es de ₡250 000.

El programa debe solicitar:
● Monto a retirar en cada operación.
● Confirmación para continuar retirando (s / n).

Utilice las siguientes reglas:
● El retiro mínimo por operación es de ₡5 000.
● El retiro máximo por operación es de ₡100 000.
● Si el monto supera el saldo disponible, no se realiza el retiro y se muestra un
mensaje.
● El ciclo continúa mientras el usuario escriba "s" y exista saldo disponible.
● Al finalizar, se muestra el saldo restante y la cantidad de retiros exitosos.

El programa debe mostrar: por cada intento, si el retiro se realizó o no, el saldo actualizado,
y al final el saldo restante y el total de retiros exitosos.
